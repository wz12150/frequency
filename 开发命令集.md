5、手机启动Metro：
app: npm run start
调试（在另一个终端）: npm   run android

手机调试版打包命令
cd app
npm install
cd andriod
app:npx react-native bundle --platform android --dev false --entry-file index.js --bundle-output android/app/src/main/assets/index.android.bundle --assets-dest android/app/src/main/res
.\gradlew clean assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk

正式版打包命令
cd app
cd android
.\gradlew clean
adb install -r app/build/outputs/apk/release/app-release.apk
